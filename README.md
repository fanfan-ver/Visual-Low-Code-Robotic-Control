# Visual-Low-Code-Robotic-Control
Official implementation of "A Visual Low-Code Robotic Control Framework with Hybrid Semantic-Geometric Perception for Non-Expert Operators"
## 📂 Model Weights
Due to GitHub file size limits, model weights are hosted separately:

1. **YOLOv8 Segmentation**: Download `yoloe-v8s-seg.pt` from our [Releases page](../../releases).
2. **VLM (Florence-2)**: Download from [Hugging Face](https://huggingface.co/microsoft/Florence-2-base).

Please place these files into the `models/` and `models_vlm/` directories before running the system.
